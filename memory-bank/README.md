# SAP AMS Application Memory Bank

This folder is the maintained project context for contributors and AI coding
assistants. Read these files before making substantial changes:

1. [Project brief](./projectbrief.md) — purpose, scope, and major capabilities.
2. [Product context](./productContext.md) — user needs and expected workflows.
3. [System patterns](./systemPatterns.md) — architecture and implementation
   conventions.
4. [Technical context](./techContext.md) — stack, local setup, environment, and
   database notes.
5. [Active context](./activeContext.md) — current known focus and caveats.
6. [Progress](./progress.md) — verified project state and follow-up checks.
7. [Product context](./productContext.md) — includes the requested multi-project
   transition-planning feature and its initial requirements.

## Maintenance

- Keep statements tied to the checked-in implementation; label deployment
  assumptions and unverified behavior.
- Update the relevant page when a feature, architecture, setup instruction, or
  database migration changes.
- Never copy credentials, tokens, customer records, or values from `.env` into
  this documentation.
- Recheck command names and environment variables against the package manifests
  and `server/.env.example` before changing setup instructions.
